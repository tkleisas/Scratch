## Full description (max 4000)

Scratch is a vinyl-first two-deck DJ app built for Android.

Load music from your local library and mix on two responsive platters. Scratch, jog, nudge and spin back with low-latency native audio, then shape the mix with an eight-node graphical EQ, independent LP/HP filters, tempo control, key lock and BPM sync.

Build a set with persistent deck queues, queue presets and four-second or custom loops. Set cue points and four hot cues per deck, and use slip mode to return scratches to the live timeline. Choose a whole-track or scrolling waveform view with a BPM-configurable window and overview minimap. When tracks need to change, the queue can auto-crossfade into the next track with a live waveform handoff.

When it is time to perform, use per-deck and master FX racks with Filter, Crush, Echo, Reverb, Tape, Compressor and Limiter. Each rack has an ordered insert chain and independent punch pads, with Hold and Latch modes.

FEATURES

• Two vinyl platters with scratch, jog and spin-back
• Tempo 50–200%, WSOLA key lock, and deck-to-deck BPM sync
• Eight-node graphical EQ with live pre/post spectra
• Independent low-pass and high-pass filters on each deck
• Loops with IN/OUT points and one-tap LOOP
• Cue points, four hot cues per deck, and slip scratching
• Whole-track and scrolling waveforms with a configurable BPM window
• Queue auto-crossfade with a ghost waveform handoff
• Optional Ableton Link tempo/phase sync on your local network
• Last-session restore, queue reordering, and next-track display
• Beat-phase SYNC with on-demand BPM and beat-grid analysis
• Per-rack FX: ordered insert chains plus seven punch pads
• Filter, Crush, Echo, Plate Reverb, Tape, Compressor and Limiter
• Local library search with persistent queues and queue presets
• WAV, AIFF, MP3, FLAC, OGG/Vorbis and Opus support
• Classic, High Contrast, Midnight and Ember themes
• Autoplay, crossfader, channel volume and saved settings
• Landscape interface for phones and tablets

PRIVACY

Scratch is local-first. It does not collect, transmit, sell or share personal data. There are no accounts, ads, analytics or tracking SDKs. Android includes network permissions solely for the optional, off-by-default Ableton Link setting, which discovers other Link apps on the local network; no music or library data is uploaded. Library metadata, queues, presets, FX state and decoded audio caches stay on the device. Read the privacy policy at https://tkleisas.github.io/scratch/privacy/.

REQUIREMENTS

Android 10 or newer. A local music library is required. Headphones or speakers are recommended for low-latency monitoring.

Scratch is a Bokontep music project.

## Release notes (v0.6.0)

Optional Ableton Link support now works on Android, Linux, and Windows for local-network tempo and beat-phase sync. Link is off by default and only exchanges timing/session state on the LAN. Android also gains network permissions solely for Link discovery. The crossfade waveform can be switched between the existing Sweep view and a Centered dual-layer view for A/B comparison. This release includes all 0.5.0 queue, session, search, beat-sync, hall-reverb, and waveform improvements.
